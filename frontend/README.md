# Cyber Defense Command Centre — Frontend

A professional military/SOC-style React frontend for the Cyber Defense for Military Networks digital twin.

## Run

```bash
npm install
npm run dev
```

## Included
- Command Centre dashboard
- Incident intelligence
- Attack graph and attack progression
- Prediction engine UI
- Human-in-the-loop response workflow
- What-If response simulation
- Live telemetry presentation
- Pipeline health
- Asset inventory
- Military network topology map
- Reports page
- Responsive layout

The UI currently uses realistic repository-derived demo data and is structured so the API/WebSocket adapters can be connected to the existing FastAPI backend.
